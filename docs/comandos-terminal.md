| Comando | Función |
| :--- | :--- |
| `cd ../..` | Sube dos niveles seguidos en las carpetas. |
| `cd tmp` | Entra en la carpeta `tmp` (directorio temporal). |
| `mkdir nombreclase` | Crea una nueva carpeta con el nombre que elijas. |
| `cd nombreclase` | Entra en la carpeta que acabas de crear. |
| `touch nombrearchivo.txt` | Crea un archivo de texto vacío con el nombre que elijas. |
| `cd ../..` | Sale de la carpeta actual subiendo dos niveles hacia atrás. |
